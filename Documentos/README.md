# Documentación Técnica y Casos de Prueba

Esta carpeta contiene la documentación formal y las matrices de verificación del sistema para la **Cooperativa de Lanchas de Taganga**:

- **Análisis y Diseño:** Especificación de los 14 requisitos funcionales, modelo de datos (`Lancha` y `Cooperativa`) y diagramas de flujo/clases.
- **Matriz de Pruebas:** Casos de prueba unitarios y de integración (incluyendo validación de fechas extremas, manejo de archivos CSV con codificación UTF-8-SIG y verificación de cálculos estadísticos).
- **Manual de Usuario:** Guía de operación en consola para las 7 opciones del menú principal y formato esperado de los archivos de entrada.
