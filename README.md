# Descripción del proyecto
Aplicación de consola en Python estructurada en dos capas (`business_logic.py` y `user_interface.py`) para gestionar el registro diario de pasajeros, indicadores estadísticos, rachas críticas, simulación y carga desde archivos CSV de las lanchas de la Cooperativa de Taganga (14 requisitos funcionales + 6 requisitos agregados).

# Cómo ejecutar el programa
1. Clonar el repositorio o descargar los archivos en una misma carpeta local.
2. Abrir una terminal en la carpeta raíz y ejecutar:
  
  ```bash
python user_interface.py
```
